CityLink - Public Transport Manager App for Object-Oriented Paradigms course.

In this project, I implemented a public transport network planner and manager system. When the user first run the app, it shows the main menu with two buttons to Access the passenger menu and the admin menu. In admin menu, which can be accessed by a simulated password page (username: admin, password: admin). In this menu, admins can Add New Route with the relevant line name, average speed, capacity and price information. Remove Selected Route menu is used to remove those routes. Add Service Alerts page is used to inform passengers about the incidents occured about the routes, with providing a line name, start date, end date and an alert message, and the Remove Service Alerts page is used to remove those alerts. Add Schedule Info page is used to add the schedule info of the routes to the system. Admins can add first vehicle time, last vehicle time, waiting time in rush hour and waiting time in regular hours information to the system to the use of the passengers. It also gives the flexibility to easly adjust the schedules for a seasonal schedule change, and the Remove Schedule page is used to remove that respective info from the system.
In passenger menu, passengers can Buy Tickets, Buy Passes and Subscriptions, Calculate Fares, View Service Alerts, View Routes, and View Schedule Info. In the Buy Tickets and Buy Passses and Subscriptions menus, users are requried to provide a valid username in TCNO format, which is checked by an custom exception calling a Luhn algorithm checker class. If the user can provide a valid username, he is directed to a payment page simulating the payment. If everything is filled correctly, the system saves ticketing info into .txt files, and also the transaction logs. Calculate Fares page is used to just learn the prices of the tickets of the selected route. View Service Alerts page is used to display the service alerts entered like delays and cancellations into the system by the admin menu Add Service Alerts to the passengers. View Routes page displays all the relevant info about the selected route. View Schedule Info page displays the schedule info of routes like first and last service hours, and waiting times in different times of the day.
In this project all pages are designed as a separate JForm file. All the respective data is stored in separate .txt files with using “;” notation as separators. The project has designed to be less hard-coded as possible, but unfortunately, the subscription prices are hard-coded for now.
